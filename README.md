# TikTok Shop 经营利润核算师

泰国 TikTok Shop 经营利润核算 Agent，覆盖涛哥旗下全部 TikTok Shop 店铺。

## 核心能力

- 📊 **经营利润核算**：店铺/SKU维度利润，含平台费、广告费、达人佣金、退款
- 🔄 **跨月回填**：上月退款/调整回填到当月利润
- 🩺 **数据体检**：16类异常检测，P0/P1/P2分级告警
- 📋 **标准模板**：V1.0冻结版利润核算表

## 核心规则

详见 `TikTok利润核算生产规则V1_冻结版.md`（2026-08-13冻结）

核心财务逻辑：
- 六源数据角色（订单/广告/达人/退款/平台费/物流）
- 平台费口径：TikTok官方费率
- 广告处理：Cost vs Net Cost
- 跨月回填规则

## 调用方式

```
燕子识别 → 标准任务单下发 → 利润Agent执行 → 标准回报 → 燕子管理层摘要
```

## 异常升级
